# Thes — релизы / Releases

Публичные установщики **Thes** для Windows.

Public **Thes** Windows installers.

## Русский

**Thes** — VPN-клиент (sing-box): split по сайтам/приложениям или полный туннель. Подписки Happ/Enot, free-каталоги, закрытие мешающих VPN (Happ), Игры/Drops.

- Скачай последний `Thes-Setup-*.exe` ниже (Releases)
- Запускай **от администратора**
- Настройки сохраняются в `%AppData%\Thes\`

Полная документация (RU+EN) в исходниках: https://github.com/1Thes1/thes (private) → `README.md`, `docs/`

## English

**Thes** is a Windows VPN client (sing-box): split by site/app or full tunnel. Happ/Enot subscriptions, free catalogs, close conflicting VPNs (Happ), Games/Drops.

- Download the latest `Thes-Setup-*.exe` from Releases
- Run **as Administrator**
- Settings live in `%AppData%\Thes\`

Full docs (RU+EN) in the private source repo: https://github.com/1Thes1/thes → `README.md`, `docs/`
