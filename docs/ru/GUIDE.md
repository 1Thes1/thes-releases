# Thes — руководство пользователя

## Установка

1. Скачай последний `Thes-Setup-*.exe`:  
   https://github.com/1Thes1/thes-releases/releases/latest  
2. Установи. Данные лежат в `%AppData%\Thes\` и **не удаляются** при обновлении.
3. Запускай Thes **от имени администратора** — иначе TUN не поднимется.

## Первое подключение

1. Открой **Подписки**.
2. Вставь URL подписки (Happ, Enot и т.п.) → **Подтянуть**.
3. Если стран мало или пусто — проверь **HWID** в Настройках (панели вроде Enot отдают список только с HWID).
4. На **Серверах** выбери страну/ноду → **Подключить**.

Рекомендуется: режим **split** + **локальный DNS** (вкл. по умолчанию) — так меньше страдает домашний Wi‑Fi.

## Split: сайты и программы

Вкладка **Split**:

- добавь домены (например `youtube.com`) — трафик к ним через VPN;
- добавь `.exe` игр/мессенджеров при необходимости;
- весь браузер в VPN класть не нужно — достаточно сайтов.

## Happ и другие VPN

**Нельзя** держать Thes и Happ одновременно: два туннеля (`happ-tun` + `thes-tun`) ломают DNS и Wi‑Fi у всех дома.

Если Thes пишет про Happ:

1. Нажми **Закрыть мешающий VPN** на баннере, **или**
2. При «Подключить» согласись закрыть Happ и подключиться, **или**
3. Закрой Happ вручную: трей → **Выход** (не просто крестик окна).

Thes должен быть от администратора, иначе Windows не даст убить процесс Happ.

## Бесплатные ноды

Вкладка **Бесплатные** — публичные каталоги. Качество нестабильное: используй **Лучший + подключить** и дождись dial. Мёртвые ноды Thes банит на время и крутит failover.

## Обновления

**Настройки → Обновления → Проверить обновления**.  
Установщики берутся из публичного `thes-releases`. Настройки в `%AppData%\Thes\` сохраняются.

Можно выбрать старую версию из списка и нажать установить (откат).

## Игры и Drops (бета)

Вкладки включаются в настройках / по флагу:

- **Игры** — библиотека Steam/Epic, запуск, подсказки по VPN.
- **Drops** — Twitch Drops: кампании и уведомления о claim.

## Типичные проблемы

| Симптом | Что сделать |
|--------|-------------|
| «Без прав — TUN не заработает» | ПКМ по Thes → от имени администратора |
| Конфликт Happ / happ-tun | Закрыть мешающий VPN или Выход из Happ |
| Упал домашний Wi‑Fi | Не запускай два VPN; перезапусти роутер при необходимости |
| Нет стран в списке | HWID + обновить подписку |
| Долго «Подключаю…» | Отмена → другой сервер / Лучший + подключить |
| После обновления «пустые» настройки | Проверь `%AppData%\Thes\`; настройки не должны жить в Program Files |

## Где что лежит

| Путь | Содержимое |
|------|------------|
| `%AppData%\Thes\` | settings, подписка, пинги, update.json |
| Установка | обычно `Program Files\Thes` или выбранная папка |
| Логи | в данных приложения / диагностика в Настройках |
